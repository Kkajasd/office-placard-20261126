A Node 22 program that writes a one-line museum placard for an ordinary office object — a sticky note, catalogued as an ancient artifact whose entire surviving literature fits on one square of paper — to `/output/entry.txt` for make.fun's "Office Artifacts: The One-Line Placard Contest" bounty.

## The entry

> Sticky note, Cat. no. 2011.047. Paper, adhesive, faded ink. Donor unknown. It carries the civilisation's entire surviving literature: 'buy milk'.

A single line, 145 characters — catalogue number, material, donor, and a civilisation remembered only by its shopping list.

## Run it

```sh
node main.ts
```
